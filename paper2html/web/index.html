连接模型

支持 Chat Completions 兼容接口。论文文本将发送到你填写的服务地址；启用视觉核对时也会发送相关论文页和原图。

密钥不写入任务文件或浏览器存储，刷新页面后需重新填写。

高级选项与补充出版信息

纯文本 API 可关闭视觉核对。单张完整位图会自动提取；矢量或复合图需要提供已检查的区域。坐标使用 PDF 点。

续跑需重新选择相同 PDF，并填写相同接口、模型、选项和补充信息；密钥可以重新提供。旧版本任务不支持续跑。

仅在 PDF 缺失信息时填写。支持 title、authors、journal、journal_abbr、publication_date（YYYYMMDD）、doi、short_name。补充信息按用户提供记录，不视为原文已核实。
